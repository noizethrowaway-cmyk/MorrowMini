# Morrow simple mortgage planner
Mobile-first static planner with three-step onboarding and plain-language mortgage snapshot.

## Publish on GitHub Pages
Upload `index.html` to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/(root)`, then save.

## Notes
Saved plans are stored in this browser's local storage. Start over clears that saved plan. Illustrations use simplified assumptions, not lender-grade calculations or personal financial advice. Check overpayment rules, limits and fees with your lender.
